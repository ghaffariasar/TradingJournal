# مستندات فنی پروژه

## معماری
این پروژه از الگوی **MVC (Model-View-Controller)** با استفاده از **ASP.NET Core 8.0** پیروی می‌کند.

### ۱. لایه داده (Data Layer)
- **ApplicationDbContext**: مدیریت ارتباط با پایگاه داده از طریق EF Core.
- **مدل‌ها**:
    - `Trade`: موجودیت اصلی برای ذخیره داده‌های معاملات.
    - `ApplicationUser`: مدل سفارشی برای مدیریت کاربران.
    - `SystemSetting`: ذخیره‌سازی تنظیمات عمومی (مانند فعال‌سازی ثبت‌نام).
    - `AppPermission`: کنترل دسترسی بر اساس مجوزها.

### ۲. امنیت
- **احراز هویت**: استفاده از Cookie-based Authentication.
- **سطوح دسترسی**: کنترل دسترسی بر اساس نقش (RBAC) شامل نقش‌های Admin, Trader, Operator.
- **مجوزهای جزئی**: تفکیک دسترسی مدیریت حساب‌های معاملاتی (`Accounts.Manage`) از اطلاعات پایه (`Lookups.Manage`).
- **ایزولاسیون داده**: اعمال فیلترهای خودکار در لایه Controller برای جلوگیری از نشت اطلاعات بین کاربران.
- **رمزنگاری**: استفاده از BCrypt برای ذخیره امن رمزهای عبور.
- **اعتبارسنجی**: اعتبارسنجی سمت سرور و کلاینت برای تمامی ورودی‌ها.
- **Anti-Forgery**: فعال‌سازی محافظت CSRF برای تمامی درخواست‌های POST.

### ۳. بومی‌سازی (Localization)
- **منابع (Resources)**: استفاده از فایل‌های `.resx` برای ترجمه‌های فارسی و انگلیسی.
- **میان‌افزار (Middleware)**: تشخیص زبان از طریق URL، کوکی یا هدر.
- **تقویم**: پشتیبانی همزمان از تاریخ میلادی و شمسی (جلالی).

### ۴. اجزای فرانت‌اِند
- **داشبورد**: یکپارچه‌سازی با `Chart.js` برای نمایش بصری داده‌ها.
- **جداول**: استفاده از `DataTables.net` برای نمایش پیشرفته لیست‌ها.
- **فرم‌ها**: استفاده از `Select2` برای لیست‌های کشویی و `Persian Datepicker` برای تاریخ‌های شمسی.
- **واکنش‌گرایی**: سیستم ریسپانسیو اختصاصی برای تمامی جداول سیستم جهت نمایش صحیح در موبایل (`table-responsive`).

## مهاجرت‌های پایگاه داده (Migrations)
برای افزودن مهاجرت جدید:
```bash
dotnet ef migrations add MigrationName
dotnet ef database update
```

## ساختار پوشه‌بندی
- `Controllers/`: منطق برنامه.
- `Models/`: موجودیت‌های دیتابیس و ViewModelها.
- `Views/`: قالب‌های Razor.
- `wwwroot/`: فایل‌های استاتیک (CSS, JS, Libs).
- `Resources/`: فایل‌های بومی‌سازی.
